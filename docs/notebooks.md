# Notebooks

`notebooks/` is the guided tour of PSBD-ViT. The reading order with a paragraph per notebook lives in `notebooks/README.md`. This page used to repeat it and went stale when the notebooks were rebuilt on 2026-09-29. It now only points there so a second copy cannot drift again.

Every notebook runs on CPU from cached results, embeds its figures and renders its result sentences from the data, asserting each against `paper/tables/*.macros.json`. Each is generated by a builder in `notebooks/build/` (see `notebooks/build/README.md`). Re-execute a notebook from the repository root with:

```bash
PYTHONPATH=. .venv/bin/python -m jupyter nbconvert --to notebook --execute --inplace \
    notebooks/<name>.ipynb --ExecutePreprocessor.timeout=1800
```

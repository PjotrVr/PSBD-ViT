# Notebook builders

Every notebook in `notebooks/` is generated by a script here, so its prose and its checks can be rebuilt when the results move. A builder writes cells whose result sentences are rendered from the data and asserted against `paper/tables/*.macros.json`, so a rebuild either restates the new value or fails.

## Rebuilding

Run a builder from the repository root with `cd notebooks/build && PYTHONPATH=../.. ../../.venv/bin/python build_<name>.py`, then execute the notebook with `.venv/bin/jupyter nbconvert --to notebook --execute --inplace notebooks/<name>.ipynb`. `nbbuild.py` and `mdpatch.py` are the shared helpers the builders import.
